# AI Literacy for College Students

A single-page, Canvas-friendly AI literacy mission game for college students.

## What is included

- Seven interactive AI literacy missions
- One bonus AI tools resource guide
- Student name entry
- Sequential mini-lesson acknowledgements
- Randomized quiz answer order
- Try It Challenge copy button
- Personalized downloadable trophy badge
- Teacher completion email button using `mailto:`
- Canvas iframe embed snippet

## Local testing

Open `index.html` in a browser.

## Canvas embed

After publishing with GitHub Pages, copy the published URL into `canvas-embed-snippet.html`.

## Customizing school colors

Edit these variables near the top of `index.html`:

```css
--school-blue: #174f8a;
--school-gold: #d7a928;
--school-accent: #26735d;
```

## Notes

This project is intentionally self-contained. It does not require a backend, database, build step, or external JavaScript library.
